Dashboard

Everything on the main dashboard — what each section does and how to use it. If this is your first time running the suite, start with First-Run Setup below.

First-Run Setup

The first time you start the suite, a setup page asks you to pick your integration provider. This controls which services the suite talks to for scrobbling, watchlists, and watch history.

Simkl — uses Simkl.tv for all scrobbling, history, ratings, and watchlist features. Link your Simkl account afterwards.

MDBList — uses MDBList.com instead. Enter your MDBList API key on the Settings page.

Both — scrobbles and syncs to both services at the same time.

None — disables external scrobbling. The suite still works for library management, downloads, and local features.

You can change this at any time from the Settings page under "Integration Provider".

Emby Webhook

The suite needs an Emby webhook to receive playback events for scrobbling, activity logging, and the smart queue feedback loop.

1. In Emby, go to Settings → Notifications → Webhooks (or Server → Webhooks on some versions).

2. Add a new webhook with URL: http://YOUR-SUITE-IP:8000/webhook/emby

3. Enable the following events:

Library — New media added, Media removed

Playback — Start, Pause, Unpause, Stop

Users — Mark Played

4. Test by playing something briefly in Emby — the activity log on the dashboard should show the event.

Library → New media added is used for real-time arrival detection and library cache updates. Without it, new content only appears after the nightly cache rebuild. Media removed keeps the library cache and Simkl watchlist in sync when you delete items.

Sonarr Webhook (optional)

Connecting Sonarr's webhook gives episode-level import tracking on the Airing Soon card and grab/import events in the activity log.

1. In Sonarr, go to Settings → Connect → + and choose Webhook.

2. Set the URL to: http://YOUR-SUITE-IP:8000/webhook/sonarr/

3. Enable: On File Import, On Import Complete, and optionally On Series Add (cosmetic activity log entry only).

4. Click Test in Sonarr — the activity log should show "Sonarr test webhook received".

The Emby webhook already handles arrival detection for both movies and shows. The Sonarr webhook adds the green "Imported" badge on individual episodes in Airing Soon and the grab/import distinction in the activity log.

User Selector & Status Bar

The dropdown at the top lets you pick which linked Emby user to view the dashboard for. All cards update for the selected user.

API — whether the suite's backend is reachable.

Linked Users — how many Emby accounts have a Simkl account connected.

Active Parties — Watch Party sessions currently running. Hover to see codes and members.

Library Cache — how many items are indexed. If 0, hit Rebuild Cache below.

Cache & Library

Shows cache statistics and a count of movies and series in your Emby library.

Cached Keys

The number of items indexed in Redis from your Emby library. Each movie and series gets its own cache entry, keyed by provider ID (IMDB, TMDB, TVDB) and title. Features like the Smart Queue, watch history, and universe discovery look items up here instead of calling the Emby API every time.

Hit Rate

The percentage of cache lookups that found a matching item. A hit rate below 100% is normal — misses happen whenever a feature looks up an item that isn't in your Emby library, such as Simkl trending content you don't own, watchlist items you haven't acquired yet, or backfilled watch history entries for things you've since deleted. These misses don't indicate a problem.

Rebuild Cache re-indexes your Emby library into Redis. Runs nightly but can be triggered manually after adding a lot of content.

Link Simkl Account

Used during initial setup when Simkl is your chosen provider. Enter your Emby User ID and username, click Get Code, then follow the on-screen instructions to authorise via Simkl. You won't need this again unless you add a new user.

If you're using MDBList only, skip this section — just enter your API key in Settings instead.

Feature Cards

The feature cards are hidden by default. Click Show on the "FEATURES" bar to reveal them.

🎯 Smart Watch Queue

Builds a personalised list of what to watch next. Pulls from your Simkl or MDBList watchlist, trending content, and calendar data, then cross-references against your Emby library. Items are ranked by weighted score.

Refresh Now rebuilds the queue immediately (normally runs daily at 2 AM).

View Queue opens the full queue table. Each row shows title, score, source, and library status.

Items not in your library show a Radarr or Sonarr button to send them to download.

Fully watched items are filtered out automatically. Shows disappear once every episode is watched.
🤖 ML Rating Predictor

Trains a model on your Simkl rating history, then predicts what score you'd give every unwatched item.

Train Model kicks off training (also runs weekly). View Predictions opens the Predictions page.

🌌 Universe Discovery

Scans your library for shared cinematic universes and creates ordered Emby playlists.

Scan Library runs matching (also weekly). View Lists opens the Lists page where you can re-order, add items, or create custom universes.

📅 Airing Soon

Upcoming episodes and movies for the next 30 days, from Sonarr and Radarr calendars. Premieres and finales are flagged. Binge plans show how many episodes per day to catch up before a finale.

Streaming logos appear when a TMDB key is configured. An "Upcoming Digital / Physical Releases" section shows monitored movies with approaching home release dates.

Each item shows a status badge. When Sonarr sends a webhook on import complete, episodes that have just arrived show a green "Imported" badge. Otherwise you'll see "In Sonarr" or "In Radarr" if the item is being monitored.

Opening Airing Soon triggers a background watchlist sync (at most once every 30 minutes). This pushes any missing Radarr/Sonarr items to your Simkl or MDBList watchlist so they appear here.

🔍 Scrobble Audit

Finds items played in Emby but missing from your watch history. When both Simkl and MDBList are active, the audit checks both services and merges the results. Backfilling pushes to whichever providers are active.

Run Audit compares your Emby played items and shows gaps. Each item gets a Backfill button; Backfill All fixes everything at once.

Shows are compared episode by episode, so a series you've only partly watched still gets audited — any individual episode missing from Simkl is flagged, whether or not the series is complete.

📊 Taste Drift

Charts how your viewing preferences have shifted over time, built from snapshots taken each time the ML model retrains.

⏸️ Continue Watching

Lists partially watched movies and in-progress shows. Each item shows a progress bar, time since last watched, and an IMDb link.

Play button

Starts playback on your Emby device. One device plays immediately; multiple devices show a picker. Shows with multiple in-progress episodes show an episode picker first. Playback resumes from where you left off.

Simkl Sync

🔄 Simkl Sync compares Emby resume points with Simkl. Flags out-of-sync items and stale entries (>30 days). Delete stale Simkl entries with the ✕ button.

📥 New & Coming Soon

Recently Arrived (green highlight) — items that were pending but have since downloaded. Dismiss with ✕ or wait 24 hours for auto-expiry.

Still Pending — items monitored but not yet available.

First deploy seeds the baseline. Arrivals appear from the second check onwards.
⬇️ Active Downloads

Live download progress for everything currently being grabbed by Radarr and Sonarr. Each item shows a progress bar, percentage, ETA, and file size. Show downloads are grouped when multiple episodes download at once.

When SABnzbd is configured in Settings, progress data comes directly from SABnzbd instead of Radarr/Sonarr, giving smoother real-time updates. A status label shows the current stage — Downloading, Repairing, Verifying, Extracting, or Moving. Download speed is shown alongside the ETA. The dashboard polls SABnzbd every 500ms while downloads are active, then drops back to a slower poll when idle.

Without SABnzbd configured, the card still works using progress data from Radarr/Sonarr, which updates less frequently.

Watchlist Sync

Bi-directional sync between Radarr/Sonarr and your Simkl or MDBList watchlist. When both providers are active, it syncs to both.

Arr → Watchlist — takes items that are monitored but don't have files yet, and adds them to your watchlist. This means they show up in Airing Soon and your smart queue.

Watchlist → Arr — takes items from your watchlist and adds them to Radarr or Sonarr if they're not already there.

Both directions can be toggled independently in Settings. The sync runs at startup, daily at 2:30 AM, and in the background when you open Airing Soon (throttled to once every 30 minutes).

The Watchlist Sync button on the dashboard triggers a manual run.

Scheduler

The scheduler grid on the dashboard shows all background jobs, their schedule, and when they last ran. Jobs include the library cache rebuild, smart queue refresh, ML model retraining, universe scan, bias analysis, watchlist sync, and library health scan. Click Show ▾ to expand the grid and Hide ▴ to collapse it. The grid refreshes every 60 seconds while visible.

SSL Certificate

Only shown if an SSL domain is configured. Displays the current certificate status, expiry date, and days remaining. The certificate auto-renews before it expires.

Activity Log

Live feed of suite activity at the bottom of the page. Playback events are consolidated into single lines — one for start, one for pause, one for resume, one for stop — instead of separate entries per provider. Scrobbling to Simkl and MDBList still happens in the background; the log just shows the result. Filter by All, Webhook, Playback, or General. Updates every 30 seconds.

Typical flow for a watch session:

Started Watching: Movie Name — Synced → Movie Name: Paused → Movie Name: Continued → Stopped Watching: Movie Name — Synced

Errors from either provider surface as separate lines so they're easy to spot.

Navigation Bar

The dark bar across the top of every page links to Dashboard, Lists, Predictions, Taste Profile, Rewatch, Stats, Watch History, Library Health, Settings, Watch Party, and this Guide. The theme toggle in the top-right switches between dark and light mode.

📋 Lists

Browse, manage, and build watch-order playlists for shared cinematic universes in your library.

Overview

This page shows every shared universe detected in your Emby library — Marvel, Star Wars, DC, Harry Potter, and more. Each universe card shows which items you own, what you've watched, and the recommended watch order. A search bar at the top filters universes by name.

Scan Now re-runs the universe matching process against your library. This also triggers auto-discovery if enabled, resolves provider IDs, matches items to your library, and rebuilds any enabled Emby playlists. The scan takes a few minutes on larger libraries.

Use Scan Now whenever you want changes to take effect — enabling a playlist toggle, adding items, or picking up newly downloaded movies.

Auto-Discovery

The first time you visit this page, a popup asks whether to enable auto-discovery. When enabled, each scan checks your Emby library for movies that belong to TMDB collections (e.g. Shrek, Toy Story, Pirates of the Caribbean). If 3 or more movies from the same collection are in your library, a new universe is created automatically with the full collection lineup and description.

Auto-discovery requires a TMDB API key configured in Settings. It only creates universes for collections not already covered by the built-in list. You can change this setting at any time.

Universe Cards

Each card shows the universe name, completion percentage (a progress bar of how much you've watched), the total item count, and a "next recommended" item — the first unwatched entry in the watch order.

Click the card header to expand and see the full item list. Items you own are shown normally; missing items are dimmed with a checkbox next to them for sending to Radarr.

Drag to Reorder

Inside an expanded card, drag items by the grip handle (⠿) to rearrange the watch order. The new order is saved automatically. Hit Scan Now to rebuild the Emby playlist in the new order.

Add Items

Click + Add Item at the bottom of an expanded card. Enter the title (required), year, and optionally an IMDB or TMDB ID for more accurate matching. The item is added to the end of the watch order and matched against your library.

Create a Universe

Click + Create Universe at the top of the page. Enter a name and optional description. The new universe starts empty — add items to build it out. Useful for custom franchises or personal viewing orders the auto-scan doesn't cover.

Playlist Toggle

Each universe has a playlist toggle. When enabled, an ordered Emby playlist is created and kept in sync with the watch order shown on this page. You can also set a custom playlist name and description.

After enabling the playlist toggle, hit Scan Now to create the Emby playlist. A page refresh only reloads the data — it doesn't build playlists.

Send Missing to Radarr

Tick the checkboxes next to missing items and click 📥 Send to Radarr. If you have two Radarr servers configured, a picker lets you choose which one. Items are added with your configured quality profile.

Delete a Universe

The 🗑️ button on a card permanently removes a universe and all its items. You'll be asked to confirm. This also removes the Emby playlist if one existed.

🤖 Predictions

Browse ML rating predictions for every unwatched item in your library.

Overview

This page shows what the ML model thinks you'd rate each unwatched item, sorted from highest to lowest predicted score. The model trains on your Simkl rating history and learns your preferences for genres, directors, actors, eras, and more.

🔄 Retrain Model kicks off a fresh training run using your latest ratings.

Two tabs switch between Top Predictions (the item cards) and Insights (genre-level analysis).

Rating Distribution

A histogram at the top groups all predictions into rating bands (5–6, 6–7, 7–8, 8–9, 9–10). Gives a quick picture of how much of your unwatched library the model thinks you'll like.

Prediction Cards

Each card shows the title, predicted rating (out of 10), and a confidence badge (high, medium, or low). Click a card to expand it and see the item overview plus the reasons behind the prediction — which genres, actors, or patterns matched your rating history.

Model Stats

Four stat cards below the histogram show the model's health: typical error (how far off predictions usually are), training data count (how many rated items it learned from), when it was last trained, and how many features it uses.

Insights Tab

Switch to the Insights tab to see genre-level cards showing the delta between your average rating and Simkl's community average for each genre. Positive deltas mean you rate that genre higher than most people.

🎓 Taste Profile

A deep analysis of your rating patterns, biases, and viewing blind spots.

Overview

This page analyses your entire Simkl rating history to show how you rate compared to the crowd. It identifies biases, hidden gems, and genres you might be overlooking.

🔄 Refresh Analysis re-runs the analysis against your latest Simkl data.

Summary stats at the top show your total ratings, average score, and which genres and eras you lean toward.

Rating Curve

A bar chart showing how many times you've used each rating from 1–10. Most people skew high — this shows your personal distribution and whether you tend to be generous or tough.

Genre Breakdown

Two views — a horizontal bar chart of your top 10 genres by average rating, and a scrollable list of every genre with your average score, count, and bias score. The bias score compares your rating to the Simkl community average: positive means you rate that genre higher than most.

A search box filters the genre list by name.

Era Preferences

A line chart plotting your average rating by decade. Shows whether you prefer classic or modern content. Below it, a card list breaks down each era with count, average, and rating range.

Hidden Gems

Items where your rating is significantly higher than the community average. The "gap" badge shows how far apart they are. These are your personal favourites that most people underrate. A search box filters by title.

Challenges

Suggested viewing challenges based on gaps in your rating history. Each has a difficulty level (easy, medium, hard). Challenges push you to explore genres or eras you haven't rated much.

Against Your Taste

Recommendations for content that sits outside your usual preferences. Each item shows a "diversity gain" score — how much it would broaden your viewing patterns. Good for breaking out of a comfort zone.

🔁 Rewatch Recommender

Surfaces items you've already watched and rated highly that are worth revisiting. Uses your rating history, time since last watch, and seasonal context to build recommendations.

How It Works

The recommender pulls your watch history and ratings from Simkl (preferred), MDBList, or Emby as a fallback. It builds a pool of items you rated 8 or higher that you watched at least 12 months ago, then ranks them using four scoring factors: your rating, how long since you last watched (staleness), whether the item matches the current season (horror in October, holiday films in December), and whether you watched it around this same date in a prior year (anniversary rewatch).

The suggestions rebuild automatically every day at 2:15 AM and are cached for 24 hours. Use the 🔄 Refresh button to force an immediate rebuild.

Poster Cards

The page displays up to 30 items in a 6-column poster grid. Each card shows the poster image, title, year, your rating, and a recommendation tag explaining why it was surfaced — things like "Watched 2 years ago", "Halloween pick", or "Anniversary rewatch".

Use the All / Movies / TV Shows filter buttons at the top to narrow by type. The grid reflows automatically — no blank spaces.

Items not in your Emby library appear with a dimmed poster and a "Not in Library" badge. Click the ✕ in the corner of any card to permanently dismiss it from future suggestions.

Watch History Flyout

Hover over a card (or tap on mobile) to see a flyout panel showing your full watch history for that item — every recorded watch date, ordered newest first. Data comes from the local watch history database for instant loading, with fallbacks to Simkl and Emby if the item hasn't been backfilled yet.

Settings

Three settings can be adjusted on the Settings page under "Rewatch Recommender":

Minimum rating — only suggest items you rated at or above this threshold (default: 8).

Minimum months since last watch — how long ago you must have watched something before it becomes eligible (default: 12 months).

Seasonal suggestions — when enabled, genre-matched items get a scoring boost based on the current month.

If the rewatch page shows no suggestions, try lowering the minimum rating to 7 and minimum months to 6 in Settings. The defaults are conservative — most people need to adjust them once.

📊 Stats

Your watching statistics powered by the local watch history database — no external API calls needed. Stats load instantly and update automatically when you watch something new.

Overview Tab

A user selector at the top lets you pick which linked account to view. Summary cards show hours watched this week, this month, this year, and all time, plus total items and average items per watching day.

Below the summary, four chart pairs sit in rows: a daily watch-time bar chart (last 30 days) paired with a genre breakdown doughnut, then peak watching hours paired with a movies vs TV split doughnut.

The genre chart requires genres to be populated on your watch history entries. After your first watch history import, run 🎭 Backfill Genres in Settings to fill them in. New watches recorded via webhooks get genres automatically.

Top People, Studios & Networks

Leaderboard-style ranked lists showing your most watched actors, directors, studios, and networks. Each entry shows how many items you've watched featuring that person or studio. Top shows are ranked by unique episode count — duplicate entries from overlapping backfill sources are deduplicated automatically.

Hover over any actor or director entry to see a details popup listing their full filmography from your library.

Fun Stats

A collection of interesting stats about your watching habits: favourite day of the week, longest watch streak (with date range), biggest binge day (with item list on hover), total unique movies and shows watched, longest movie, and how many days you've been tracking.

A day-of-week bar chart shows which days you watch the most.

Most Rewatched Movies

A ranked list of movies you've watched more than once, ordered by play count. Each entry shows the title, number of plays, last watched date, and an IMDb link. Items without a title are filtered out automatically.

Trends Tab

Two visualisations for longer-term patterns:

Year-over-Year — a line chart with one line per year, overlaid on the same Jan–Dec axis. Makes it easy to compare whether you're watching more or less than previous years.

Activity Heatmap — a GitHub-style grid showing watch activity by day over the last 12 months. Darker cells mean more items watched. Hover over any cell to see the date, item count, and hours. A legend at the bottom shows the intensity scale.

Queue Feedback Tab

Shows how well the Smart Queue's recommendations are working. Summary cards show total recommended, played, play rate, and period. A source play-rate chart and current weights chart sit side by side, followed by a table of recent recommendations with their source, score, and whether you played them.

This data feeds back into the Smart Queue's weight-learning algorithm — over time, it adjusts which sources (watchlist, trending, calendar) it prioritises based on what you actually watch.

📜 Watch History

A visual timeline of everything you've watched, grouped by date. Works like the history view on Simkl or MDBList, but built from your local watch history database with thumbnails pulled straight from your Emby server.

Overview

Each date that has watch activity gets its own row, newest first. Under the date heading, every item watched that day appears as a landscape thumbnail card. Dates with no activity are skipped entirely.

A user selector at the top lets you switch between linked accounts.

This page reads from the same local watch_history table that powers the Stats page and Rewatch Recommender. If your history looks sparse, run 📥 Import Watch History in Settings.

Filters

Four buttons at the top control what's shown:

All — everything you've watched.

Movies — movies only.

Shows — collapses episodes into one card per series per day. Shows how many episodes you watched as a subtitle (e.g. "3 episodes"). Uses the series poster instead of individual episode thumbnails.

Episodes — TV episodes only, shown individually.

Switching filters reloads the timeline from the most recent date.

My Ratings & Floating Rating Bar

A ⭐ My Ratings button in the header opens a panel showing all your user-submitted ratings with poster thumbnails, filterable by source (user vs imported).

At the bottom of the page, a floating rating bar shows up to 5 recently watched items you haven't rated yet. Tap a number 1–10 to rate instantly — the rating is pushed to Simkl and MDBList simultaneously and stored locally. Click ✕ to permanently dismiss an item from the prompt. Rated items fade out and are replaced with the next unrated item.

Episode ratings are stored locally only — neither Simkl nor MDBList support episode-level ratings.

Item Cards

Movies show the film title with "Movie" underneath. Episodes show the series name with the episode code below it, formatted as Series Name S01 E03.

If you watched the same item more than once on the same day, it appears once with a count badge in the top-right corner — 2×, 3×, and so on.

Duplicate entries from overlapping sources (webhook plus backfill) are merged automatically, so a single watch won't be double-counted.

Partial Watches

The timeline shows everything you started, not just what you finished. Items you didn't complete display an orange progress bar along the bottom of the thumbnail, filled to represent how much you watched, with the time remaining shown above it — for example "23 min left" or "1h 12m left".

Anything under 2% watched is filtered out, so accidental opens don't clutter the timeline.

Thumbnails

Images come directly from your Emby server over the local network. Movies use their landscape thumb image; episodes use their own episode screenshot rather than the series poster.

Images load lazily as you scroll, so opening a long history doesn't fire hundreds of requests at once. If an image is missing, the card falls back to an icon with the title.

Loading More

The page loads 30 days of history at a time. A Load more button at the bottom fetches the next 30 days going further back. The button disappears once you reach the end of your history.

🎬 Item Detail

A full-page breakdown of any movie or show — poster, ratings from multiple sources, cast and crew, your personal watch history, and quick actions.

Overview

The item detail page aggregates data from Emby, MDBList, TMDB, and the local database into a single view. It loads all sources in parallel, so the page fills in as each source responds. A blurred backdrop image from Emby sets the visual tone behind the content.

The page works for both movies and TV shows. The URL format is /item/{imdb_id}, with optional query parameters ?type=movie or ?type=show and &emby_id=... for faster image loading.

How to Get There

There's no item detail link in the navigation bar — you reach it from other pages:

Watch History — click any item title underneath a thumbnail card. This is the most common entry point.

Library Health — titles in the Incomplete Series, Watched Not in Library, and Simkl Suggestions tables link to IMDB externally. Items that have an IMDB ID can be opened on the detail page by navigating to /item/{imdb_id} directly.

Direct URL — type /item/tt1234567 in your browser with any valid IMDB ID to open that item's detail page.

The ← Back link at the top of the page returns you to wherever you came from.

Hero Section

The top of the page shows the poster on the left and key information on the right:

Poster — pulled from your Emby server. Falls back to a placeholder icon if the item isn't in your library.

Logo — if TMDB has a logo image for the title (common for popular franchises), it displays above the title text.

Tagline — the film's tagline from TMDB, shown in italics below the title.

Meta pills — year, content rating (PG-13, R, TV-MA), runtime, and status (Released, Returning Series, Ended). Shows display season and episode counts instead of runtime.

Genres — clickable genre tags from TMDB.

Overview — the plot synopsis. Long overviews are truncated with a "Show more ▾" toggle.

Details — additional metadata rows for directors, writers, studios, networks, budget, and revenue when available.

Ratings

A horizontal row of rating cards from multiple sources, each showing the score out of 10 and the number of votes. Sources include IMDb, Trakt, TMDb, Rotten Tomatoes, Metacritic, and MDBList. Only sources with data are shown.

If you've submitted a personal rating (via the floating rating bar on Watch History or directly through Simkl/MDBList), it appears as a highlighted card labelled "Your Rating" alongside the external scores.

Action Buttons

▶ Play on Emby — starts playback on your active Emby device. Only appears when the item is in your library. If you have multiple active sessions, a device picker appears.

▶ Watch Trailer — opens the TMDB trailer link in a new tab. Only appears when TMDB has a trailer for the item.

Cast & Crew

A tabbed section with Cast and Crew tabs, each showing a count badge. Cast members display in a grid of photo cards with the actor's name and character role. Crew members show name and job title (Director, Writer, Producer, etc.).

Photos come from TMDB. Members without a photo show a silhouette placeholder. The grid is responsive — more columns on wider screens, fewer on mobile.

Your Watch History

If you've watched this item before, a timeline appears showing every recorded watch event with the date and completion percentage. Fully completed watches show in green; partial watches show the percentage in amber. Data comes from the local watch history database.

This section only appears when there's at least one watch event for the item.

Keywords

A row of keyword chips from TMDB — things like "based on novel", "time travel", "superhero". Limited to 15 keywords with a "+N more" indicator if there are extras. Useful for understanding what themes a film covers.

⚙️ Settings

Configure connections, features, schedules, and integrations.

Integration Provider

Choose which services the suite uses for scrobbling, watch history, and watchlists. Options are Simkl, MDBList, Both, or None. Changing this controls which sections appear below and which services receive your playback data.

When set to "Both", every playback event scrobbles to Simkl and MDBList simultaneously. Watchlist sync, scrobble audit, and history all work with whichever providers are active.

MDBList

Only shown when MDBList is selected as a provider. Enter your MDBList API key (found on your MDBList account page) and save.

Sync New pushes your Simkl watch history and ratings to MDBList since the last sync (delta sync). Full Re-sync pushes everything from scratch. Check Status compares the two services and shows how many items are missing from MDBList.

MDBList scrobbling only works for movies — their API doesn't support TV episode scrobble. TV episodes are tracked via history sync instead, which fires when playback stops.

Emby Configuration

Enter your Emby server URL and API key. A connection badge shows live status. Test Connection verifies the server is reachable before saving.

Feature Toggles

Toggle switches to enable or disable individual features: Smart Watch Queue, ML Rating Predictor, Universe Discovery, and Watch Party Sync. Disabled features stop their background jobs and hide their dashboard cards.

Smart Queue Options

S01E01 only — when enabled, the Smart Queue playlist adds only Season 1 Episode 1 of each show instead of the full series. Good for discovery.

Queue Blocklist

Items you've permanently dismissed from the Smart Queue. Click Load Blocklist to see them. Unblock any item to let it appear in future refreshes.

Scheduler

Set the time and frequency for each background job: Smart Queue refresh (default daily 2 AM), ML model retraining (default weekly Monday 4 AM), and Universe scan (default weekly Sunday 3 AM). All times are UTC.

Database Backup

Create Backup generates a SQL dump of all data (users, watch parties, ML models, universes, ratings). Download the file to keep it safe. To restore, upload a previously exported .sql file. Restoring overwrites all current data.

A separate Universes Export/Import section lets you export all universes as JSON and import them on another instance.

Radarr Integration

Connect up to two Radarr servers (e.g. one for 1080p, one for 4K). Enter a name, URL, and API key for each. Test verifies the connection and loads quality profiles. Choose which profile to use, then save.

Auto-send missing movies — toggle this on to automatically send all missing Smart Queue movies to Radarr when the queue refreshes. Off by default.

Sonarr Integration

Same setup as Radarr but for TV shows. Up to two servers, test, choose quality profile, save. The auto-send toggle works the same way.

SABnzbd Integration

Connect up to two SABnzbd servers for real-time download progress on the Active Downloads card. When configured, SABnzbd replaces the stale progress numbers from Radarr/Sonarr with live data straight from the download client.

Enter the SABnzbd URL and API key for each server. The API key is found in SABnzbd's web UI under Config → General → API Key. Click Test to verify the connection, then save.

The connection badge next to the section header shows live status. SABnzbd is checked every 5 minutes alongside Emby, Simkl, Radarr, and Sonarr.

SABnzbd is optional. Without it, the Active Downloads card still works using progress data from Radarr/Sonarr — it just updates less frequently.

Watchlist Sync

Bi-directional sync between your download managers and your Simkl or MDBList watchlist. When both providers are active, items are synced to both. Two independent toggles:

Arr → Watchlist — syncs monitored-but-missing Radarr/Sonarr items to your watchlist so they appear in Airing Soon.

Watchlist → Arr — auto-adds watchlist items to Radarr/Sonarr (uses first configured server).

Runs at startup, daily at 2:30 AM, and in the background when you open Airing Soon.

TMDB API

Optional. Enter a free TMDB API key to enable streaming service logos on Airing Soon items. Test the key before saving.

Simkl List Import

Displays your personal Simkl lists. Click Import to Emby next to any list to create an Emby playlist from it. Items are matched against your library cache — unmatched items are reported.

Watch History

The suite keeps a permanent local record of every completed watch. New watches are recorded automatically via Emby webhooks. Two one-time import buttons handle your existing history:

📥 Import Watch History — pulls your complete watch history from Simkl (individual timestamps), MDBList (watched dates), and Emby (LastPlayedDate) into the local database. Duplicates are automatically skipped. Safe to re-run.

🎭 Backfill Genres — populates genre data for all imported watch history entries by querying Emby. Needed for the genre breakdown chart on the Stats page. New webhook watches get genres automatically — this button is only for backfilled data.

After first install: run Import Watch History first, then Backfill Genres. The Stats page and Rewatch Recommender both use this local data.

Trakt Data Import

Import a Trakt export zip file to migrate your entire Trakt history into the suite. Ideal for first-time setup or switching from a Trakt-based workflow.

Export your data from trakt.tv/settings/data, then upload the zip here. The parser recognises all standard Trakt export files — watched movies, watched shows (with full season/episode structure), ratings (movies, shows, episodes), watch history logs, and watchlists.

After parsing, a preview shows counts for each data category. Choose what to import with the checkboxes, then click 🚀 Confirm & Push to send to the local database, Simkl, and MDBList simultaneously.

Watched shows are imported as individual episode records — each episode from the Trakt export's season/episode structure gets its own row in the watch history table with the original watched-at date, series name, season number, and episode number. These show up on the Watch History page under the Shows filter.

Watchlist items are pushed to both Simkl (as plan-to-watch) and MDBList, keeping both providers in sync.

Ratings are batched 50 at a time at 1 request/second to stay within Simkl's rate limits. The progress bar updates in real time via Socket.IO as each batch completes, so you can see exactly where the import stands rather than waiting for a silent HTTP request to finish.

Existing items are skipped automatically — safe to re-run if your first attempt was interrupted.

Notifications

Send alerts to Discord, Gotify, or any webhook endpoint when events happen. Configure up to 5 services.

🔔 Service Types

Discord — paste a Discord channel webhook URL. Notifications appear as rich embeds with timestamps.

Gotify — enter your Gotify server URL and an app token. Notifications are pushed at priority 5.

Webhook — any HTTP endpoint. Receives a JSON POST with event, title, message, timestamp, and source fields.

⚡ Event Triggers

Scrobble — fires when playback starts or stops. Sends a single combined notification per event rather than separate ones per provider.

Arrival — fires when new content appears in your library via Radarr or Sonarr.

Premiere — fires daily at 8 AM for shows premiering or reaching their finale today.

Download — fires when a download completes and is detected by the webhook handler.

Prediction — fires after ML training when items score 8.5+ with high confidence. Off by default.

System — fires on errors like token refresh failures so you can re-link before things break.

Use the Test button next to each service to verify it's working before saving. Notifications are fire-and-forget — they never block playback or scrobbling.

Danger Zone

Three destructive actions, each requiring confirmation:

Clear Cache — removes all cached library data. Rebuilt on next sync.

Reset OAuth Credentials — disconnects all Simkl accounts. Must re-authenticate.

Factory Reset — erases all data, settings, and models. Starts from scratch.

👥 Watch Party

Watch together with synchronised playback across Emby devices.

Overview

A Watch Party lets multiple Emby users watch the same item at the same time with synchronised play, pause, and seek. The host picks the content, everyone joins with a code, and playback is controlled from one place.

Select your user from the dropdown at the top before creating or joining.

Create a Party

Search your Emby library by title, select the item, and click Create Party. You'll get a party code to share with others. Active and past parties appear in a list below.

Each active party in the list has a ✕ button to end it directly from the lobby without needing to enter it first.

Create Lobby (Pick Together)

Click 🎬 Create Lobby (Pick Together) to create a party without choosing content first. Members join via code, then the group decides what to watch together using Pick Together.

Pick Together (Theater Mode)

A group voting feature for deciding what to watch. Works in two modes:

In a Watch Party (remote)

After creating a lobby and members join, the host clicks 🎬 Pick Together. Candidate cards are pulled from each participant's smart queue (in-library, unplayed items only) and appear on everyone's screen. Each person taps to vote from their own device. Votes update in real time.

The host clicks ✓ Confirm & Start to select the winner (highest votes, tie-break by queue score). The pick panel closes and the party item is set to the winner. The host then clicks 📱 Choose Devices to pick which Emby devices to play on. After selecting devices, a 20-second countdown appears on all members' screens with a "Bring your Emby app into focus" message, then playback starts on the selected devices.

In the room (solo, one device)

On the Watch Party lobby, click the 🎬 Pick Together card. Candidates from your smart queue appear in a popup. Pass the device around — each person taps their pick (votes stack up). Click ✓ Pick Winner to select the top vote. A device picker then appears listing your active Emby sessions. Select one and hit ▶ Play to start playback directly — no party or countdown needed.

Pick Together needs items in your smart queue. If no candidates appear, run a queue refresh from the dashboard first.

Join a Party

Everyone joining must have an active Emby account and must select their username from the dropdown before joining.

Enter the party code and click Join, or click a party from the active list. The member count updates in real time as people join.

Playback Controls

The host clicks 📱 Choose Devices to see active Emby sessions. Tick the devices to play on, then confirm. A 20-second countdown broadcasts to all members, then playback starts on the selected devices.

⏸ Pause All pauses every device at the same time. Click again to resume.

⏩ Seek prompts for a timestamp (e.g. 15:30) and jumps all devices to that position.

Chat & Reactions

A live chat runs alongside playback. Type a message and press Enter or click Send. Emoji reactions (👍 😂 😮 ❤️ 😢) send a quick one-tap response visible to everyone. System messages announce joins, pauses, and seeks.

End Party

The host can end the party from the header bar. All participants see a "Party ended" message. Past parties remain in the list for reference.

🏥 Library Health

Find gaps in your library — shows you've started but not finished, things you've watched on Simkl that aren't in Emby, and related movies you might want to grab.

Overview

The Library Health page compares your Simkl watch history against your Emby library to spot anything that's out of sync or missing. Pick a user from the dropdown at the top, then click 🔍 Run Scan to start. The scan checks three things: incomplete series, watched items not in your library, and related movies you might like. Results are cached for 6 hours so the page loads instantly if you come back.

A row of summary cards at the top shows the total count for each category at a glance.

Incomplete Series

Shows in your Emby library where you've watched some episodes but not all. Each row shows the title (linked to IMDB when available), a progress bar, how many episodes you've played, and how many are left. Sorted with the most complete shows first.

Watched Movies Not in Library

Movies that appear in your Simkl watch history but aren't in your Emby library. These are things you've watched somewhere else — in a cinema, on a streaming service, or on a previous server — that aren't currently in your collection. Each row shows the title, year, and when you last watched it.

Watched Shows Not in Library

Same idea as movies, but for TV shows. Shows the title, year, how many episodes you've watched, and when you last watched. Useful for spotting series you followed on another platform but never added to Emby.

Simkl Suggestions

For every movie you rated 8 or higher on Simkl, the scan checks Simkl's related movies and flags any that aren't in your library. Each row links to IMDB or TMDB for quick reference. Limited to 3 suggestions per source item, and self-suggestions are filtered out even when titles differ slightly (punctuation, subtitles).

Dismissing Items

Not every "missing" item is actually something you want. Cinema-only watches, one-off streaming views, and films you don't plan to collect will all show up. Click the ✕ button on any row to dismiss it. Dismissed items are saved to the database and won't reappear on future scans.

Sending an item to Radarr or Sonarr also auto-dismisses it, so you won't see it again even if the download hasn't finished yet.

To bring everything back, click Restore Dismissed in the scan info bar at the top of the results. This clears all dismissals and the items will return on the next scan.

Send to Radarr / Sonarr

Missing movies show a 📥 Radarr button and missing shows show a 📥 Sonarr button, just like on the dashboard queue. If you have more than one Radarr or Sonarr server configured, a dropdown appears so you can pick which one. The row disappears from the table once the item is sent.

Scheduled Scans

A full library health scan runs automatically every Wednesday at 4:30 AM for all linked users. You can also run a manual scan at any time from the page. Results are cached for 6 hours, so loading the page between scans is instant.

The scan checks items against the library cache, not Emby directly. If you've just added new content, rebuild the cache first (from the dashboard) so the scan picks it up.
