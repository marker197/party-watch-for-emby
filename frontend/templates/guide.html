Dashboard

Everything on the main dashboard — what each section does and how to use it.

User Selector & Status Bar

The dropdown at the top lets you pick which linked Emby user to view the dashboard for. All cards update for the selected user.

API — whether the suite's backend is reachable.

Linked Users — how many Emby accounts have a Trakt account connected.

Active Parties — Watch Party sessions currently running. Hover to see codes and members.

Library Cache — how many items are indexed. If 0, hit Rebuild Cache below.

Cache & Library

Shows cache statistics (total keys, hit rate, last rebuild) and a count of movies and series in your library.

Rebuild Cache re-indexes your Emby library into Redis. Runs nightly but can be triggered manually.

Link Trakt Account

Used during initial setup. Enter your Emby User ID and username, click Get Code, then follow the on-screen instructions to authorise via Trakt. You won't need this again unless you add a new user.

Feature Cards

The feature cards are hidden by default. Click Show on the "FEATURES" bar to reveal them.

🎯 Smart Watch Queue

Builds a personalised list of what to watch next. Pulls from your Trakt watchlist, trending content, and calendar data, then cross-references against your Emby library. Items are ranked by weighted score.

Refresh Now rebuilds the queue immediately (normally runs daily at 2 AM).

View Queue opens the full queue table. Each row shows title, score, source, and library status.

Weight History shows how scoring weights have shifted over time.

Items not in your library show a Radarr or Sonarr button to send them to download.

Fully watched items are filtered out automatically. Shows disappear once every episode is watched.
🤖 ML Rating Predictor

Trains a model on your Trakt rating history, then predicts what score you'd give every unwatched item.

Train Model kicks off training (also runs weekly). View Predictions opens the Predictions page.

🌌 Universe Discovery

Scans your library for shared cinematic universes and creates ordered Emby playlists.

Scan Library runs matching (also weekly). View Universes opens the Universes page where you can re-order, add items, or create custom universes.

📅 Airing Soon

Upcoming episodes and movies for the next 30 days, from Sonarr and Radarr calendars. Premieres and finales are flagged. Binge plans show how many episodes per day to catch up before a finale.

Streaming logos appear when a TMDB key is configured. An "Upcoming Digital / Physical Releases" section shows monitored movies with approaching home release dates.

🔍 Scrobble Audit

Finds items played in Emby but missing from Trakt history. Run Audit compares both and shows gaps. Each item gets a Backfill button; Backfill All fixes everything at once.

📊 Taste Drift

Charts how your viewing preferences have shifted over time, built from snapshots taken each time the ML model retrains.

⏸️ Continue Watching

Lists partially watched movies and in-progress shows. Each item shows a progress bar, time since last watched, and an IMDb link.

Play button

Starts playback on your Emby device. One device plays immediately; multiple devices show a picker. Shows with multiple in-progress episodes show an episode picker first. Playback resumes from where you left off.

Trakt Sync

🔄 Trakt Sync compares Emby resume points with Trakt. Flags out-of-sync items and stale entries (>30 days). Delete stale Trakt entries with the ✕ button.

📥 New & Coming Soon

Recently Arrived (green highlight) — items that were pending but have since downloaded. Dismiss with ✕ or wait 24 hours for auto-expiry.

Still Pending — items monitored but not yet available.

First deploy seeds the baseline. Arrivals appear from the second check onwards.
⬇️ Active Downloads

Live download progress from Radarr and Sonarr — progress bar, percentage, ETA, and file size. Show downloads are grouped when multiple episodes download at once.

Activity Log

Live feed of suite activity at the bottom of the page. Filter by All, Webhook, Trakt, Playback, or General. Updates every 30 seconds.

Navigation Bar

The dark bar across the top of every page links to Dashboard, Universes, Predictions, Taste Profile, Stats, Settings, and Watch Party. The theme toggle in the top-right switches between dark and light mode.

🌌 Universes

Browse, manage, and build watch-order playlists for shared cinematic universes in your library.

Overview

This page shows every shared universe detected in your Emby library — Marvel, Star Wars, DC, Harry Potter, and more. Each universe card shows which items you own, what you've watched, and the recommended watch order. A search bar at the top filters universes by name.

Scan Now re-runs the universe matching process against your library. This also triggers auto-discovery if enabled, resolves provider IDs, matches items to your library, and rebuilds any enabled Emby playlists. The scan takes a few minutes on larger libraries.

Use Scan Now whenever you want changes to take effect — enabling a playlist toggle, adding items, or picking up newly downloaded movies.

Auto-Discovery

The first time you visit this page, a popup asks whether to enable auto-discovery. When enabled, each scan checks your Emby library for movies that belong to TMDB collections (e.g. Shrek, Toy Story, Pirates of the Caribbean). If 3 or more movies from the same collection are in your library, a new universe is created automatically with the full collection lineup and description.

Auto-discovery requires a TMDB API key configured in Settings. It only creates universes for collections not already covered by the built-in list. You can change this setting at any time.

Universe Cards

Each card shows the universe name, completion percentage (a progress bar of how much you've watched), the total item count, and a "next recommended" item — the first unwatched entry in the watch order.

Click the card header to expand and see the full item list. Items you own are shown normally; missing items are dimmed with a checkbox next to them for sending to Radarr.

Drag to Reorder

Inside an expanded card, drag items by the grip handle (⠿) to rearrange the watch order. The new order is saved automatically. Hit Scan Now to rebuild the Emby playlist in the new order.

Add Items

Click + Add Item at the bottom of an expanded card. Enter the title (required), year, and optionally an IMDB or TMDB ID for more accurate matching. The item is added to the end of the watch order and matched against your library.

Create a Universe

Click + Create Universe at the top of the page. Enter a name and optional description. The new universe starts empty — add items to build it out. Useful for custom franchises or personal viewing orders the auto-scan doesn't cover.

Playlist Toggle

Each universe has a playlist toggle. When enabled, an ordered Emby playlist is created and kept in sync with the watch order shown on this page. You can also set a custom playlist name and description.

After enabling the playlist toggle, hit Scan Now to create the Emby playlist. A page refresh only reloads the data — it doesn't build playlists.

Send Missing to Radarr

Tick the checkboxes next to missing items and click 📥 Send to Radarr. If you have two Radarr servers configured, a picker lets you choose which one. Items are added with your configured quality profile.

Delete a Universe

The 🗑️ button on a card permanently removes a universe and all its items. You'll be asked to confirm. This also removes the Emby playlist if one existed.

🤖 Predictions

Browse ML rating predictions for every unwatched item in your library.

Overview

This page shows what the ML model thinks you'd rate each unwatched item, sorted from highest to lowest predicted score. The model trains on your Trakt rating history and learns your preferences for genres, directors, actors, eras, and more.

🔄 Retrain Model kicks off a fresh training run using your latest ratings.

Two tabs switch between Top Predictions (the item cards) and Insights (genre-level analysis).

Rating Distribution

A histogram at the top groups all predictions into rating bands (5–6, 6–7, 7–8, 8–9, 9–10). Gives a quick picture of how much of your unwatched library the model thinks you'll like.

Prediction Cards

Each card shows the title, predicted rating (out of 10), and a confidence badge (high, medium, or low). Click a card to expand it and see the item overview plus the reasons behind the prediction — which genres, actors, or patterns matched your rating history.

Model Stats

Four stat cards below the histogram show the model's health: typical error (how far off predictions usually are), training data count (how many rated items it learned from), when it was last trained, and how many features it uses.

Insights Tab

Switch to the Insights tab to see genre-level cards showing the delta between your average rating and Trakt's community average for each genre. Positive deltas mean you rate that genre higher than most people.

🎓 Taste Profile

A deep analysis of your rating patterns, biases, and viewing blind spots.

Overview

This page analyses your entire Trakt rating history to show how you rate compared to the crowd. It identifies biases, hidden gems, and genres you might be overlooking.

🔄 Refresh Analysis re-runs the analysis against your latest Trakt data.

Summary stats at the top show your total ratings, average score, and which genres and eras you lean toward.

Rating Curve

A bar chart showing how many times you've used each rating from 1–10. Most people skew high — this shows your personal distribution and whether you tend to be generous or tough.

Genre Breakdown

Two views — a horizontal bar chart of your top 10 genres by average rating, and a scrollable list of every genre with your average score, count, and bias score. The bias score compares your rating to the Trakt community average: positive means you rate that genre higher than most.

A search box filters the genre list by name.

Era Preferences

A line chart plotting your average rating by decade. Shows whether you prefer classic or modern content. Below it, a card list breaks down each era with count, average, and rating range.

Hidden Gems

Items where your rating is significantly higher than the community average. The "gap" badge shows how far apart they are. These are your personal favourites that most people underrate. A search box filters by title.

Challenges

Suggested viewing challenges based on gaps in your rating history. Each has a difficulty level (easy, medium, hard). Challenges push you to explore genres or eras you haven't rated much.

Against Your Taste

Recommendations for content that sits outside your usual preferences. Each item shows a "diversity gain" score — how much it would broaden your viewing patterns. Good for breaking out of a comfort zone.

📊 Stats

Your watching statistics and history at a glance.

Overview Tab

A user selector at the top lets you pick which linked account to view. The overview shows summary stats for total hours watched, items completed, average rating, and current streak.

Below the stats row, two charts sit side by side — a genre breakdown (pie or bar chart of watch time by genre) and a monthly watch history (bar chart showing hours watched per month).

Trends Tab

Two visualisations for longer-term patterns:

Year-over-Year — a line chart with one line per year, overlaid on the same Jan–Dec axis. Makes it easy to compare whether you're watching more or less than previous years.

Activity Heatmap — a GitHub-style grid showing watch activity by day. Darker cells mean more items watched. Hover over any cell to see the date, item count, and hours. A legend at the bottom shows the intensity scale.

Queue Feedback Tab

Shows how well the Smart Queue's recommendations are working. A table lists recently recommended items with their source, score, and whether you played them or not. "Played" items are marked green; items you ignored stay grey.

This data feeds back into the Smart Queue's weight-learning algorithm — over time, it adjusts which sources (watchlist, trending, calendar) it prioritises based on what you actually watch.

⚙️ Settings

Configure connections, features, schedules, and integrations.

Emby Configuration

Enter your Emby server URL and API key. A connection badge shows live status. Test Connection verifies the server is reachable before saving.

Feature Toggles

Toggle switches to enable or disable individual features: Smart Watch Queue, ML Rating Predictor, Universe Discovery, and Watch Party Sync. Disabled features stop their background jobs and hide their dashboard cards.

Smart Queue Options

S01E01 only — when enabled, the Smart Queue playlist adds only Season 1 Episode 1 of each show instead of the full series. Good for discovery.

Queue Blocklist

Items you've permanently dismissed from the Smart Queue. Click Load Blocklist to see them. Unblock any item to let it appear in future refreshes.

Scheduler

Set the time and frequency for each background job: Smart Queue refresh (default daily 2 AM), ML model retraining (default weekly Monday 4 AM), and Universe scan (default weekly Sunday 3 AM). All times are UTC.

Database Backup

Create Backup generates a SQL dump of all data (users, watch parties, ML models, universes, ratings). Download the file to keep it safe. To restore, upload a previously exported .sql file. Restoring overwrites all current data.

A separate Universes Export/Import section lets you export all universes as JSON and import them on another instance.

Radarr Integration

Connect up to two Radarr servers (e.g. one for 1080p, one for 4K). Enter a name, URL, and API key for each. Test verifies the connection and loads quality profiles. Choose which profile to use, then save.

Auto-send missing movies — toggle this on to automatically send all missing Smart Queue movies to Radarr when the queue refreshes. Off by default.

Sonarr Integration

Same setup as Radarr but for TV shows. Up to two servers, test, choose quality profile, save. The auto-send toggle works the same way.

Watchlist Sync

Bi-directional sync between your download managers and Trakt watchlist. Two independent toggles:

Arr → Watchlist — syncs monitored-but-missing Radarr/Sonarr items to your Trakt watchlist so they appear in Airing Soon.

Watchlist → Arr — auto-adds Trakt watchlist items to Radarr/Sonarr (uses first configured server).

Runs at startup, daily at 2:30 AM, and in the background when you open Airing Soon.

TMDB API

Optional. Enter a free TMDB API key to enable streaming service logos on Airing Soon items. Test the key before saving.

Trakt List Import

Displays your personal Trakt lists. Click Import to Emby next to any list to create an Emby playlist from it. Items are matched against your library cache — unmatched items are reported.

Danger Zone

Three destructive actions, each requiring confirmation:

Clear Cache — removes all cached library data. Rebuilt on next sync.

Reset OAuth Credentials — disconnects all Trakt accounts. Must re-authenticate.

Factory Reset — erases all data, settings, and models. Starts from scratch.

👥 Watch Party

Watch together with synchronised playback across Emby devices.

Overview

A Watch Party lets multiple Emby users watch the same item at the same time with synchronised play, pause, and seek. The host picks the content, everyone joins with a code, and playback is controlled from one place.

Select your user from the dropdown at the top before creating or joining.

Create a Party

Search your Emby library by title, select the item, and click 🎉 Create Party. You'll get a party code to share with others. Active and past parties appear in a list below.

Join a Party

Everyone joining a party must have an active account on the Emby server and must select their username from the user dropdown at the top of the page before joining.

Enter the party code and click Join. You can also join by clicking a party from the active list. The member count updates in real time as people join.

Playback Controls

Once inside a party, the host clicks ▶ Start Playback. Devices are listed with checkboxes — tick the ones to play on, then confirm. Playback starts on all selected devices at the same time.

⏸ Pause All pauses every device simultaneously. Click again to resume.

⏩ Seek prompts for a timestamp (e.g. 15:30) and jumps all devices to that position.

Chat & Reactions

A live chat runs alongside playback. Type a message and press Enter or click Send. Emoji reactions (👍 😂 😮 ❤️ 😢) send a quick one-tap response visible to everyone. System messages announce joins, pauses, and seeks.

End Party

The host can end the party from the header bar. All participants see a "Party ended" message. Past parties remain in the list for reference.
