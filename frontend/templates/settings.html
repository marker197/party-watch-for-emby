📥 Radarr Integration —

Connect up to 2 Radarr servers for sending missing universe items to download. Typically one for 1080p and one for 4K.

Auto-send missing movies Automatically send all missing queue movies to Radarr when the queue refreshes (off by default)

📺 Sonarr Integration —

Connect up to 2 Sonarr servers for sending missing TV shows to download. Typically one for 1080p and one for 4K.

Auto-send missing shows Automatically send all missing queue shows to Sonarr when the queue refreshes (off by default)

⬇️ SABnzbd Integration —

Connect up to 2 SABnzbd servers for real-time download progress. Replaces the stale progress from Radarr/Sonarr with live data from the download client.

🔄 Watchlist Sync

Bi-directional sync between Radarr/Sonarr and your Trakt watchlist. Runs at startup, daily at 2:30 AM, and in the background when you open Airing Soon.

Arr → Watchlist Sync missing Radarr/Sonarr items (monitored, no file) to your Trakt watchlist so they appear in Airing Soon
Watchlist → Arr Auto-add Trakt watchlist items to Radarr/Sonarr if not already there (uses first configured server)

🎬 TMDB API

Optional. Enables streaming service logos on Airing Soon items. Get a free API key at themoviedb.org.

📋 MDBList —

Optional. Import MDBList lists as Emby playlists with auto-sync. Dynamic lists update automatically every morning. Get a free API key at mdblist.com/preferences.

Push your Trakt watched history, ratings, and show progress into MDBList. After the first full sync, subsequent syncs only push new items.
