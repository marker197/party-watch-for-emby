Welcome to Emby-Simkl Suite

Choose which services to integrate with for scrobbling, watchlist sync, and watch history.

Simkl Only Recommended
Full integration with Simkl.tv — scrobbling, watchlist sync, ratings, watch history, and all suite features. Requires a Simkl account and OAuth setup.
MDBList Only Beta
Full integration with MDBList — scrobbling, watchlist sync, watched history, ratings, and list management. Requires an MDBList API key.
Both
Dual integration — scrobble to both services simultaneously. Watch history, ratings, and watchlists synced to both Simkl and MDBList.
None
Skip external integrations. The suite will still manage your Emby library, smart queue, and predictions using Emby data only.

You can change this anytime in Settings.
